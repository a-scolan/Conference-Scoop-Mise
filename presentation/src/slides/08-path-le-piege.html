> 03 // PATH WINDOWS · LE PIÈGE DU MASQUAGE

Le piège du PATH : HKLM passe toujours avant HKCU

[ 01 // REGISTRY ] [!]

HKLM passe avant HKCU

À la création de session (CreateEnvironmentBlock), Windows concatène le PATH Machine (HKLM) avant le PATH Utilisateur (HKCU). Changer cet ordre exige de modifier HKLM, donc des droits administrateur : sans eux, on agit sur la session ou le profil.

[ 02 // COLLISION ] [!]

Masquage silencieux

Si l'image entreprise contient un vieux Python 3.9 dans C:\Python39 déclaré au niveau Machine, votre Python 3.12 installé via Mise passe après lui : dans un terminal ordinaire, c'est l'exécutable machine qui répond.
