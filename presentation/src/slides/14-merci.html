Installer ses outils de dev avec Scoop & Mise

ANTISÈCHE · COMMANDES DU QUOTIDIEN LIENS : scoop.sh/#/apps · mise.jdx.dev
[ SCOOP : GESTION DES OUTILS ]
> scoop search <terme>
> scoop install <paquet>
> scoop update * (met à jour tout)
> scoop hold <paquet> (figer version)
> scoop bucket add <nom> <url-git>
[ MISE : RUNTIMES DU PROJET ]
> mise use node@22 python@3.12
> mise install (selon mise.toml)
> mise upgrade (mise à jour runtimes)
> mise ls (versions installées)
> mise run <task> (tâches d'équipe)
