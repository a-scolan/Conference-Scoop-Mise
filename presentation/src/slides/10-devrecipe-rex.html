> 04 // DEVRECIPE · FONCTIONNEMENT

DevRecipe : manifeste, préflight, décision

[ 01 // MANIFESTE ] [OK]

Un manifeste relu en PR

DevRecipe_windows.toml liste, par profil, les paquets Scoop et les runtimes Mise. -Validate contrôle la syntaxe sans toucher au poste.

[ 02 // PRÉFLIGHT ] [!]

Chercher les traces avant d'écrire

-DryRun parcourt le registre, AppX, les services et les tâches. Il ne modifie rien et s'arrête si une installation existe déjà.

[ 03 // DÉCISION ] [?]

Vous cochez ce que vous forcez

Si le préflight trouve une installation existante, une liste s'affiche : chaque conflit est coché ou refusé. Rien n'est forcé par défaut. Sans terminal interactif, DevRecipe s'arrête (code 3).

[ 04 // ENVIRONNEMENT ] [OK]

Outils et runtimes en place

Scoop installe les paquets, Mise les runtimes. DevRecipe place aussi les shims en tête de PATH, dans PowerShell et dans cmd.exe via AutoRun.
