> 04 // DEVRECIPE · L'ORCHESTRATION D'ÉQUIPE

DevRecipe : combler les limites de Scoop et Mise

[ 01 // UNIFICATION ] [OK]

Manifeste devrecipe.toml partagé

Scoop et Mise s'ignorent mutuellement. DevRecipe les rassemble dans un fichier partagé, versionné et relu en PR pour répondre aux besoins collectifs de l'équipe.

[ 02 // PREFLIGHT ] [OK]

Contrôle préalable des conflits

Ni Scoop ni Mise n'inspectent les logiciels déjà présents. DevRecipe scanne le registre, AppX et le PATH pour alerter avant toute modification.

[ 03 // PRECEDENCE ] [OK]

Précédence du PATH garantie

DevRecipe injecte les shims en priorité 0 dans PowerShell et dans cmd.exe (via AutoRun), neutralisant le masquage machine HKLM.
