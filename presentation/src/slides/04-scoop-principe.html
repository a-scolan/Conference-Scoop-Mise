01 Scoop · Espace Utilisateur

Scoop : vos outils dans votre profil, sans admin

[ ░▒▓ PRINCIPE #1 ▓▒░ ] ZERO_UAC [ ■ ]
PROFIL UTILISATEUR

Zéro UAC

Scoop décompresse les binaires dans ~/scoop/apps. Aucun installeur MSI ne pollue le registre machine ni n'exige de droit élevé.

[ ░▒▓ PRINCIPE #2 ▓▒░ ] SHIMS_ROUTING [ ■ ]
PASSE-PLATS (SHIMS)

Relais d'exécution

Un seul dossier dans votre PATH : ~/scoop/shims. Chaque outil y dépose un petit proxy (.exe / .cmd) pointant sur la version active.

[ ░▒▓ PRINCIPE #3 ▓▒░ ] GIT_BUCKETS [ ■ ]
CATALOGUES GIT

Dépôts de recettes

Les catalogues d'applications (buckets) sont de simples dépôts Git de manifests JSON (main, extras ou vos recettes internes d'entreprise).
