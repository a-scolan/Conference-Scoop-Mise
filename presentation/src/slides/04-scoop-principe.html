> 01 // SCOOP · ESPACE UTILISATEUR

Vos outils dans votre profil utilisateur, sans droits admin

[ 01 // PROFIL USER ] [OK]

Zéro UAC

Scoop décompresse les binaires dans ~/scoop/apps. Aucun installeur MSI ne pollue la machine ni n'exige de droit.

[ 02 // SHIMS ] [OK]

Relais d'exécution (Shims)

Un seul dossier dans votre PATH : ~/scoop/shims. Chaque outil y dépose un proxy (.exe / .cmd) pointant sur la version active.

[ 03 // BUCKETS ] [OK]

Dépôts de recettes Git

Les catalogues d'outils sont de simples dépôts Git de manifests JSON (main, extras ou buckets privés d'entreprise).
